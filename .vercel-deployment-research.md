2. https://vercel.com/kb/guide/deploy-a-tanstack-start-app-to-vercel
   Vercel's guide says existing TanStack Start apps should have Nitro installed and registered in vite.config.ts. Vercel can detect TanStack Start/Nitro automatically. Git deployment: push to Git, import repository at vercel.com/new, confirm TanStack Start preset, deploy. CLI alternative: npm install -g vercel; vercel; use vercel --prod for production. Environment variable guidance: VITE_ variables are client-visible and must not contain secrets; unprefixed variables stay server-side. Verify SSR, route navigation, server functions, and use logs for failures. If framework detection fails, set framework to tanstack-start in dashboard or vercel.json.
