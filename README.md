# Gerome Umali Portfolio

This archive contains the editable source for the updated AI Automation Specialist portfolio.

## Requirements

- Node.js 22 or compatible modern Node.js version
- pnpm

## Install dependencies

```bash
pnpm install
```

## Start the development server

```bash
pnpm dev
```

## Create a production build

```bash
pnpm build
```

## Preview the production build locally

```bash
pnpm preview
```

The archive intentionally excludes `node_modules`, `.output`, `.vite`, `.wrangler`, and other generated files. Those are recreated by installing dependencies and running the relevant commands.

The source includes the latest portfolio updates, including the particle-free Aurora RUN control, demand-driven Lenis scrolling, deferred workflow and Calendly work, direct Lucide icon imports, and immediate hero first paint behavior.
